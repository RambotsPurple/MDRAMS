# MDRAMS - Mount doug's robotics site
## file structure:
    -Components -> Parts of page
    -Pages -> independent sub directories like mdrams/home or mdrmas/sponsor
    -Layout -> template for pages <slot> is where pages are injected

## Pages:

### Landing:
    - nav
    - CTA
    - Impact
    - sponsors(Sponsors US!)
    - footer

### about:
    -nav
    -origin
    -school integration
    -footer

### Sponsors US!:
    -nav
    -mission
    -current sponsors
    -contact
    -footer

## First timers that are contributing :
    Please install node js
        Run:
        1. npm install
        2. npm run build
        3. npm run dev

    dev starts the local host, build is self explanatory    
    and install gets the dependencies
